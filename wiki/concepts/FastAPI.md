**Résumé :** Framework web Python : routes, validation via [[Pydantic]], doc `/docs`. N'écoute pas le réseau lui-même : c'est uvicorn (serveur ASGI) qui reçoit les requêtes HTTP et les lui passe. Doc : fastapi.tiangolo.com/tutorial.
